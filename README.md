# Save Manager for [UNBEATABLE](https://store.steampowered.com/app/2240620/UNBEATABLE/)
Lets you manage unlockables in UNBEATABLE's arcade mode. Can NOT be used to update scores, rating or unlock titles.

## Using the Save Manager
The arcade save file is usually located at "C:\Users\user\AppData\LocalLow\D-CELL GAMES\UNBEATABLE\PROFILES\random-string-of-letters-and-numbers\Arcade-Progress.json" on Windows.

## Building the project
The project is built using Godot 4.7.1.

See: https://docs.godotengine.org/en/4.7/tutorials/export/exporting_projects.html
